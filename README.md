# IT Passport Reviewer
The IT Passport Reviewer Application is a web-based study tool designed to help students review and assess their basic knowledge of Information Technology concepts. The application focuses on fundamental IT topics commonly included in IT Passport or introductory computer examinations.

This system is developed using PHP, HTML, and CSS, making it lightweight, easy to understand, and suitable for beginners in web development. It runs on a local server environment such as XAMPP, without requiring a database.
